# In-app MCP server exposing editor tools to external agent CLIs.
# Floor is the version this is tested against: the server needs
# FastMCP(stateless_http=..., json_response=...) and
# call_tool(validate_input=False), and the transport test needs
# mcp.client.streamable_http.streamable_http_client(url, http_client=...).
# Capped below 2.0, which reorganises these APIs again.
#
# The marker skips mcp on MinGW/MSYS2 Python >= 3.14. There mcp declares
# pywin32>=311, and no pywin32 distribution exists for that interpreter: PyPI
# ships MSVC-only wheels through cp313 and MSYS2 packages 310, so pip resolution
# fails outright. Install it without its dependency graph instead:
#   pip install --no-deps "mcp>=1.28,<2"
# pywin32 itself is still REQUIRED at import time on Windows, and comes from
# pacman (MSYS2 ships 310, which is fine because --no-deps means pip never
# enforces the >=311 floor). Do not assume it is optional: importing
# mcp.server.fastmcp transitively imports mcp.client.stdio, which imports
# mcp.os.win32.utilities, whose `if sys.platform == "win32"` block imports
# pywintypes/win32api/win32con/win32job with no try/except -- the else branch
# only stubs them for non-Windows. Without pywin32 the server import dies with
# ModuleNotFoundError: No module named 'pywintypes'.
# The pins below are mcp's own runtime dependencies, kept explicit so that
# --no-deps install produces a working server. Keep them in sync with mcp's
# requires_dist when moving the floor.
mcp>=1.28,<2; sys_platform != "win32" or python_version < "3.14"
