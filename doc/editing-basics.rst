Editing Basics
==============

This guide covers the baseline editing flow for short-form and long-form projects.

Timeline essentials
-------------------

1. Add a clip to the timeline.
2. Use edge handles to trim in/out points.
3. Split clips at the playhead for structural edits.
4. Keep audio and video synchronized before adding effects.

.. tip::

   Name tracks by role (A-roll, B-roll, music, captions). It keeps complex
   timelines easier to scan and reduces accidental edits.

Review loop
-----------

Use a simple review cycle:

* Do a full playback pass for pacing.
* Fix timing issues first.
* Refine transitions and motion second.
* Run an audio pass before export.
