Start Here
==========

Zenvi is designed to make editing feel fast and predictable, even on complex
timelines. This guide walks through the default workflow and points you to
deeper docs for each area.

Core workflow
-------------

1. Create a project and choose timeline settings.
2. Import media into **Project Files**.
3. Build a rough cut on the timeline.
4. Add transitions, effects, and keyframes.
5. Preview, tweak audio, then export.

.. tip::

   Keep your first pass focused on story flow. Fine-grained animation and
   visual polish are faster once your main sequence is locked.

Quick setup checklist
---------------------

.. list-table::
   :header-rows: 1

   * - Step
     - Why it matters
   * - Set project profile
     - Matches preview/render resolution and frame rate.
   * - Organize source folders
     - Faster relinking and easier collaboration.
   * - Name timeline tracks
     - Makes automation and keyframing easier to follow.
   * - Save early versions
     - Lets you safely try major editing changes.
