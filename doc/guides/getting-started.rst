Getting Started
===============

Zenvi is optimized for short feedback loops: import footage, rough-cut quickly,
and refine with assistant-driven suggestions where needed.

Install and launch
------------------

#. Download the latest build from https://zenvi.pro/download/.
#. Launch Zenvi and create your first project.
#. Keep Auto Save enabled while you explore new workflows.

Build your first edit
---------------------

1. Drag media into the project files panel.
2. Drop clips onto the timeline and trim with handles.
3. Add transitions between adjacent clips.
4. Tune audio levels before exporting.

.. note::

   Use proxy media for high-resolution footage on lower-powered hardware.
   Playback responsiveness will improve significantly on long sequences.

Useful shortcuts
----------------

.. list-table::
   :header-rows: 1
   :widths: 30 70

   * - Shortcut
     - Action
   * - ``Space``
     - Play or pause preview.
   * - ``Ctrl + Z``
     - Undo the last change.
   * - ``Ctrl + Shift + Z``
     - Redo the previous undone change.
   * - ``I`` / ``O``
     - Set in/out points on the selected clip.
