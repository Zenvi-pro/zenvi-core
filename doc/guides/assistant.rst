Assistant Workflows
===================

The Assistant can help speed up repetitive edits while you keep full control
over final creative decisions.

Prompt structure that works
---------------------------

Use prompts that include:

1. Target output length.
2. Platform or audience.
3. Desired pacing and tone.
4. Any hard constraints.

.. code-block:: text

   Build a 45-second product teaser for YouTube Shorts.
   Keep cuts fast, use upbeat pacing, and preserve the first spoken line.

Review loop
-----------

.. tip::

   Run suggestions on a duplicate sequence first. This preserves your original
   timeline while you evaluate generated edits.

1. Generate a suggestion.
2. Scrub through each cut point.
3. Verify subtitle timing and readability.
4. Accept, tweak, or discard.
